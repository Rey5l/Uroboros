Uroboros - Android-приложение для эффективного запоминания материалов

ОПИСАНИЕ:
Uroboros - это мобильное приложение для Android, которое помогает пользователям запоминать учебные материалы с помощью метода интервальных повторений, основанного на кривой забывания Эббингауза.

ОСНОВНЫЕ ВОЗМОЖНОСТИ:

1. Управление заметками:
   - Создание заметок с названием, описанием и метками
   - Поддержка Rich Text Editor для форматирования текста
   - Система меток (тегов) для организации материалов
   - Избранные заметки для быстрого доступа
   - Поиск по названию заметок
   - Фильтрация по тегам

2. Система интервальных повторений:
   - Автоматические напоминания через 1, 3, 7 и 14 дней после создания заметки
   - Push-уведомления для напоминания о просмотре материалов
   - Интеграция с WorkManager для надежной доставки уведомлений

3. Статистика (новая функция):
   - Общее количество заметок
   - Количество избранных заметок
   - Количество уникальных тегов
   - Активность за последние 7 дней
   - Виджет статистики на странице профиля

4. Профиль пользователя:
   - Аутентификация через Firebase Auth
   - Загрузка и изменение аватара
   - Изменение имени пользователя
   - Смена пароля
   - Синхронизация данных профиля с Firebase Firestore
   - Локальное кэширование данных профиля через DataStore

5. Навигация:
   - Главная страница с отображением всех заметок
   - Страница заметок
   - Страница профиля
   - Детальный просмотр заметок

ТЕХНОЛОГИЧЕСКИЙ СТЕК:

- Язык: Kotlin
- UI: Jetpack Compose (Material 3)
- Архитектура: MVVM (Model-View-ViewModel)
- База данных: Room Database (локальное хранилище)
- Аутентификация: Firebase Authentication
- Облачное хранилище: Firebase Firestore, Firebase Storage
- Фоновые задачи: WorkManager
- Навигация: Jetpack Navigation Compose
- Изображения: Coil
- Локальное хранилище: DataStore Preferences
- Минимальная версия Android: API 26 (Android 8.0)
- Целевая версия: API 34 (Android 14)
- Тестирование: JUnit 4, Mockito, Coroutines Test
- JVM Target: 11

СТРУКТУРА ПРОЕКТА:

/data
  - Note.kt - модель заметки
  - Tag.kt - модель тега
  /db - Room Database DAO и Database классы
  /repository - репозитории для работы с данными

/view
  /components - переиспользуемые UI компоненты
  /pages - основные страницы приложения
  /screens - экраны (Login, Registration, MainScreen)
  /navigation - навигационная логика

/viewmodel
  - NoteViewModel.kt - логика работы с заметками
  - TagViewModel.kt - логика работы с тегами
  - AuthViewModel.kt - логика аутентификации

/notification
  - ReminderWorker.kt - фоновые задачи для напоминаний
  - ScheduleReminder.kt - планирование напоминаний

/ui/theme - тема приложения (цвета, типографика)

/test - Unit тесты
  /data - тесты моделей данных (Note, Tag)
  /data/db/note_db - тесты DAO слоя
  /data/repository - тесты репозиториев
  /viewmodel - тесты ViewModel слоя

ОСОБЕННОСТИ РЕАЛИЗАЦИИ:

1. Кривая забывания Эббингауза:
   - Интервалы повторений: 1, 3, 7, 14 дней
   - Автоматическое планирование напоминаний при создании заметки

2. Локальное хранилище:
   - Room Database для заметок и тегов
   - DataStore для настроек и кэша профиля
   - Автоматическое удаление тегов при удалении последней заметки с этим тегом

3. Синхронизация:
   - Firebase Firestore для хранения данных профиля
   - Firebase Storage для хранения изображений
   - Локальное кэширование для быстрого доступа

4. UX/UI:
   - Material Design 3
   - Темная и светлая темы
   - Адаптивная навигация
   - Прокручиваемые страницы
   - Тактильная обратная связь (Haptic Feedback)
