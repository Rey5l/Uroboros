# Uroboros — полное описание приложения

**Uroboros** — Android-приложение для запоминания учебных и личных материалов с помощью **интервальных повторений**. Пользователь добавляет конспекты, статьи и заметки, а приложение напоминает о них в заданные дни, помогает повторять содержимое и проверять усвоение.

- **Разработчик:** Reysl  
- **Пакет:** `com.reysl.uroboros`  
- **Версия:** 1.0  
- **Минимальная Android:** 8.0 (API 26)  
- **Целевая Android:** 14 (API 34)

---

## Идея и подход

Приложение опирается на метод интервальных повторений (spaced repetition): материал нужно возвращаться к материалу через увеличивающиеся промежутки времени — через 1, 3, 7, 14 дней и т.д. Uroboros автоматизирует напоминания и даёт инструменты для активного повторения: скрытие ключевых слов, режим чтения и AI-генерацию вопросов.

Все данные хранятся **локально** на устройстве. Авторизация и облачная синхронизация не требуются.

## Навигация

Приложение построено вокруг **трёх вкладок** нижней панели:

| Вкладка | Назначение |
|---------|------------|
| **Заметки** | Быстрый Markdown-черновик для набора и сохранения материала |
| **Главная** | Список всех материалов, поиск, фильтры, метки, избранное |
| **Настройки** | Тема, напоминания, уведомления, экспорт/импорт, статистика |

Стартовую вкладку можно выбрать в настройках (Заметки / Главная / Настройки).

## Материалы (заметки)

Каждый материал содержит:

- **Название**
- **Краткое описание**
- **Метку (тег)** — для группировки
- **Текст** в формате Markdown
- **Дату добавления**
- Флаг **«Избранное»**

### Создание материала

1. **Вкладка «Заметки»** — написать текст в редакторе и сохранить через диалог (название, описание, метка).
2. **Share Intent** — отправить текст или ссылку из другого приложения в Uroboros; приложение попытается извлечь заголовок и содержимое страницы.
3. **Главная → добавление** — через диалог нового материала.

### Главная страница

- Просмотр всех материалов карточками
- **Поиск** по названию
- **Фильтр по метке** — выбор тега из списка
- **Избранное** — только помеченные материалы
- **Сортировка:** новые, старые, А→Я, Я→А
- Счётчик материалов в заголовке

### Карточка материала

- Открытие полного экрана редактора
- Переключение **избранного**
- **Удаление** с подтверждением (метка удаляется, если больше не используется)

## Редактор материала

Экран материала (`NoteScreen`) — центральное место работы с контентом.

### Режимы

| Режим | Описание |
|-------|----------|
| **Редактирование** | Markdown-редактор с панелью форматирования |
| **Чтение** | Отрендеренный Markdown (заголовки, списки, код, ссылки) |
| **Проверка знаний** | Случайные слова в тексте скрыты — нажатие раскрывает их |
| **Вопрос по материалу** | AI-генерация вопроса с 4 вариантами ответа |

### Markdown-редактор

Текст хранится как Markdown. Панель инструментов (`RichTextToolbar`) поддерживает:

- **Undo / Redo** — отмена и повтор действий
- **Жирный**, *курсив*, ~~зачёркнутый~~, подчёркнутый (HTML-тег)
- **Заголовки** H1 и H2
- **Ссылки** — диалог ввода текста и URL
- **Inline-код** и **блоки кода** (```)
- **Цитаты** (> )
- **Маркированный** и **нумерованный** списки

В режиме редактирования блоки кода визуально выделяются прямо в поле ввода.

### Проверка знаний (офлайн)

Локальный алгоритм скрывает ~35% значимых слов (от 4 букв, без стоп-слов). Нажатие на скрытое слово показывает его. Подходит для быстрого самопроверочного чтения без интернета.

### AI-вопросы (LLM)

Генерация одного вопроса с четырьмя вариантами ответа на основе текста материала:

- Модель: **Qwen/Qwen2.5-7B-Instruct** через Hugging Face Router API
- **Лимит:** 3 генерации в день на устройство
- Сгенерированный вопрос **сохраняется в базе** и показывается при повторном открытии
- Кнопка **«Сгенерировать заново»** создаёт новый вопрос (с учётом лимита)
- Требуется `HUGGING_FACE_TOKEN` в `local.properties` и интернет

## Интервальные напоминания

Ядро приложения — система напоминаний о повторении.

### Как работает

При добавлении материала планируются уведомления на даты:

**дата создания + N дней** в выбранное **время суток**.

Интервалы по умолчанию: **1, 3, 7, 14** дней.  
Время по умолчанию: **09:00**.

### Настройки напоминаний

В **Настройки → Напоминания**:

- **Время** — TimePicker, когда приходит уведомление
- **Интервалы** — набор дней (можно добавлять, удалять, сбросить к умолчанию)
- При изменении времени или интервалов все напоминания **перепланируются** для всех материалов

### Уведомления

- Push через **WorkManager** и `ReminderWorker`
- При нажатии на уведомление открывается **соответствующий материал**
- Запрос разрешения на уведомления при каждом открытии приложения (если не выдано)
- Управление разрешением в **Настройки → Уведомления**

## Настройки

### Статистика

Виджет в верхней части настроек:

- Всего материалов
- Избранных
- Материалов за последние 7 дней

### Тема оформления

- Системная
- Светлая
- Тёмная

Тема применяется ко всему приложению, включая карточки, редактор и диалоги.

### Стартовая вкладка

Выбор вкладки при запуске: Заметки, Главная или Настройки.

### Уведомления

- Статус разрешения (разрешены / не разрешены)
- Кнопки «Разрешить» и «Открыть настройки»

### Данные

**Экспорт** — все материалы и метки в JSON-файл.  
**Импорт** — из JSON с выбором:

- **Добавить** — объединить с существующими
- **Заменить всё** — удалить текущие и загрузить из файла

Формат резервной копии: `NotesBackup` (version 1).

### О приложении

- Логотип, версия, разработчик
- Краткое описание
- Контакты: поддержка автора, Telegram-канал, обратная связь

## Импорт из других приложений

Uroboros принимает **ACTION_SEND** с `text/plain`:

- Текст или URL из браузера, мессенджера и т.д.
- Если передана ссылка — приложение загружает страницу (Jsoup) и предлагает сохранить как материал
- Диалог предзаполняет заголовок, описание и метку

## Хранение данных

| Данные | Хранилище |
|--------|-----------|
| Материалы | Room (`Note`) |
| Метки | Room (`Tag`) |
| AI-вопросы | Room (`MaterialQuiz`, один вопрос на материал) |

## Основные пользовательские сценарии

### 1. Добавить конспект и не забыть повторить

1. Написать текст на вкладке «Заметки» или принять share из браузера  
2. Сохранить с меткой «Учёба»  
3. Получать push через 1, 3, 7, 14 дней  
4. По нажатию на уведомление открыть материал и повторить  

### 2. Быстро проверить себя

1. Открыть материал  
2. Включить «Проверка знаний» — скрытые слова  
3. Или «Вопрос по материалу» — MCQ от AI  

### 3. Организовать большую базу

1. Разметить материалы метками  
2. Искать по названию, фильтровать по тегу  
3. Добавлять важное в избранное  
4. Сортировать по дате или алфавиту  

### 4. Сменить телефон / бэкап

1. Настройки → Экспорт заметок → JSON  
2. На новом устройстве → Импорт

## Ограничения и особенности

- **Подчёркивание** в Markdown через HTML (`<u>`), не все рендереры его поддерживают
- **Выравнивание текста** (слева/центр/справа) в редакторе не поддерживается — кнопки удалены
- **AI-генерация** требует токен Hugging Face с правом Inference Providers
- **Quiz:** максимум 3 новых генерации в сутки; уже сохранённый вопрос открывается без траты лимита
- При удалении материала удаляются связанные напоминания и сохранённый quiz
